# Práctica de Python para análisis de datos

Ejercicio opcional de Data Science II, módulo 1. Incluye variables, clasificación de precios, un diccionario de stock y una función de resumen estadístico.

## Ejecución

```text
python analisis_basico.py
```

La función `resumen_estadistico(numeros)` devuelve total, promedio y cantidad. Si la lista está vacía, el promedio es `None`.
